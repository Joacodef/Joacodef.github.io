The agent of the prediction note only watched: the cart was pushed at random, and it learned how long the pole would stay up. This note's agent chooses its pushes, to keep the pole up as long as it can. To choose, it needs to know what each push is worth: in a given situation, how long the pole will stay up after a push to the left, and after a push to the right. Those are values of actions, which Sarsa learned on the cliff, one per move in each cell; here, as in the prediction note, they come from a few weights shared by all the states.

Learning those values while acting on them works as Sarsa did on the cliff. The new questions are what the agent must see to choose well, and what to do when the task never ends: the last part of the note sets the pole back up after every fall, so that there are no episodes, and judges the agent by how often the pole falls, an average per step, since a total would grow without limit.

As in the prediction note, the estimates, the bars the weights set, are drawn in blue ink, and what they aim for, the target of an update, in red ink. The push just chosen is yellow.

1Values of pushes

To choose a push, the agent compares the values of its two pushes in the state it is in. With too many states for a table, it estimates them from weights, q(s, a, w) ≈ qπ(s, a), the value of taking action a in state s and following π afterwards. The features now describe a state and an action together, x(s, a), and the linear estimate weighs them as before:

q(s, a, w) ≐ wTx(s, a) = Σdi=1wixi(s, a)

Which features? The six ranges of the pole's angle that the prediction note used are not enough to choose by, for a reason in the physics of the cart. A push changes how fast the cart moves, and with it how fast the pole turns, at once; the pole's angle changes only on the steps after. An agent that sees only the angle would see the same next state whichever way it pushed, and an update that looks one step ahead could never tell its two pushes apart.

So this note's agent also sees which way the pole swings. That makes twelve situations, six ranges of the angle times two directions of swing, and for each situation one feature per push, d = 24: xi(s, a) is 1 for the situation of s and the push a, and 0 for the other 23, so q(s, a, w) is the weight of that pair. It is state aggregation again, now over pairs of a state and an action.

The weights learn as in the prediction note, from examples that now pair a state and an action with a target, St, At ↦ Ut:

wt+1 ≐ wt + α[Ut − q(St, At, wt)] ∇q(St, At, wt)

The target can be the return Gt, or one of the n-step returns of the n-step note. Sarsa's target, the reward plus the value of the next state and of the action chosen in it, gives episodic semi-gradient one-step Sarsa:

wt+1 ≐ wt + α[Rt+1 + γq(St+1, At+1, wt) − q(St, At, wt)] ∇q(St, At, wt)

It is a semi-gradient method for the reason semi-gradient TD(0) was: its target depends on the weights, and the update ignores that. For a fixed policy it converges as semi-gradient TD(0) does, to a fixed point of its own, with the same kind of bound on its error.

2Learning to keep the pole up

The values of the last section belong to the random policy. To do better, the agent acts on its own estimates, as the control methods of the earlier notes did: in the next state it computes the value of each action and takes the greedy one,

A*t+1 = argmaxa q(St+1, a, wt),

or, some of the time, a random one: ε-greedy. With two pushes this takes two lookups. With many actions, or a continuous range of them, finding the best one is a problem of its own, with no settled answer. The policy that acts is the one being learned, on-policy, so every update changes the policy a little.

The algorithm

Episodic semi-gradient Sarsa, for an estimate q differentiable in its weights, a step size α > 0 and a small ε > 0:

  1. Start with any weights w, for example all 0.
  2. At the start of each episode, observe the first state S, and choose A from q(S, ·, w), ε-greedy.
  3. Take A, and observe the reward R and the next state S′.
  4. If S′ is terminal, update w ← w + α[R − q(S, A, w)] ∇q(S, A, w), and go back to step 2 for the next episode.
  5. Otherwise choose A′ from q(S′, ·, w), ε-greedy, and update w ← w + α[R + γq(S′, A′, w) − q(S, A, w)] ∇q(S, A, w).
  6. Set S ← S′ and A ← A′, and go back to step 3.

The figure's agent explores without random pushes, with ε = 0. Instead it starts every weight at 300 steps, more than any of its episodes will last. Whatever push it tries falls short of 300 sooner or later, so the push it has not tried looks better, and it tries that one: optimism, as R-Max used it in the model-based note.

α stays at 0.1 throughout. The prediction note shrank α from one episode to the next so that its weights would settle; here they must first come down from 300, and their targets keep changing as the policy improves. With α shrunk the same way, 100 runs of 500 episodes kept the pole up 68 steps per episode over their last 100 episodes, against 182 with α fixed.

3Looking n steps ahead

The n-step return of the n-step note works with weights too, the estimate at its end taken from the weights as they stand:

Gt:t+n ≐ Rt+1 + γRt+2 + ⋯ + γn−1Rt+n + γnq(St+n, At+n, wt+n−1), t + n < T

with Gt:t+n = Gt when t + n ≥ T. It takes the place of Sarsa's target in the general update, which, as in the n-step note, updates the pair of n steps back:

wt+n ≐ wt+n−1 + α[Gt:t+n − q(St, At, wt+n−1)] ∇q(St, At, wt+n−1), 0 ≤ t < T

The algorithm

Episodic semi-gradient n-step Sarsa, with α > 0, a small ε > 0 and n ≥ 1. It keeps the last n + 1 states, actions and rewards:

  1. Start with any weights w, for example all 0.
  2. At the start of each episode, observe S0, choose A0 from q(S0, ·, w), ε-greedy, and set T ← ∞.
  3. For t = 0, 1, 2, …: if t < T, take At and observe Rt+1 and St+1; if St+1 is terminal, set T ← t + 1, and otherwise choose At+1 from q(St+1, ·, w), ε-greedy.
  4. Set τ ← t − n + 1, the time whose estimate is updated. If τ ≥ 0: G ← Σmin(τ+n, T)i=τ+1γi−τ−1Ri; if τ + n < T, G ← G + γnq(Sτ+n, Aτ+n, w); and w ← w + α[G − q(Sτ, Aτ, w)] ∇q(Sτ, Aτ, w).
  5. Repeat steps 3 and 4 until τ = T − 1, then start the next episode.

On the cart-pole, a target that looks one step ahead learns little from most steps. The pole usually stays in the same situation, so the target borrows the very weight being updated, and the TD error is 1 whatever that weight is, as in the prediction note. A target with n real rewards sees more of what a push did. With too many, though, the target is a whole return, which varies more from one episode to the next. The figure runs the agent of the last section with four values of n, 200 times each, and shows how long the pole stays up, episode by episode.

As the n-step note said, an intermediate n often does best. Here it is a large one, 16 steps, about a third of a second of the cart's motion: the twelve situations are too coarse for the estimate of the next one to stand in well for what follows it.

4A task that never ends

The cart-pole can also be posed without episodes. After every failure, the pole falling or the cart leaving the track, the cart and pole start afresh and the task goes on, with a reward of −1 at each failure and 0 at every other step. A return that adds up rewards forever would then be −∞ for every policy that ever fails. Instead of a total, a policy is judged by its average reward per step:

r(π) ≐ limh→∞ 1h Σht=1 E[Rt | S0, A0:t−1 ∼ π]

Here it is minus the rate of failures: a policy that loses the cart every 183 steps on average has r(π) = −1/183 ≈ −0.0055. The definition assumes that this long-run average does not depend on where the agent starts. The values then measure each step against it. The differential return adds up how much each reward beats the average,

Gt ≐ Rt+1 − r(π) + Rt+2 − r(π) + Rt+3 − r(π) + ⋯

and the differential values are its expectations, vπ(s) = Eπ[Gt | St = s] and qπ(s, a) = Eπ[Gt | St = s, At = a]. On the cart-pole, the differential value of a push is how many failures fewer than average follow it, in the long run.

Learning needs no new machinery. The TD error measures the reward against the estimate Rt, and adds the values of the next pair and of this one, with no discount:

δt ≐ Rt+1 − Rt + q(St+1, At+1, wt) − q(St, At, wt)

The weights follow wt+1 ≐ wt + αδt∇q(St, At, wt), and R learns from the same error with a step size of its own, R ← R + βδt: when rewards keep beating R, the TD errors are mostly positive and R rises, and the other way round.

5Differential semi-gradient n-step Sarsa

With n steps, the differential return subtracts the estimate of the average from each of its n rewards, and then borrows the estimate at its end:

Gt:t+n ≐ Rt+1 − Rt+n−1 + ⋯ + Rt+n − Rt+n−1 + q(St+n, At+n, wt+n−1)

and the n-step TD error, δt ≐ Gt:t+n − q(St, At, w), updates the weights and R as in the last section.

The algorithm

Differential semi-gradient n-step Sarsa, with step sizes α, β > 0, a small ε > 0 and n ≥ 1. It keeps the last n + 1 states, actions and rewards:

  1. Start with any weights w and any R, for example all 0.
  2. Observe S0 and choose A0 from q(S0, ·, w), ε-greedy.
  3. For t = 0, 1, 2, …: take At, observe Rt+1 and St+1, and choose At+1 from q(St+1, ·, w), ε-greedy.
  4. Set τ ← t − n + 1. If τ ≥ 0: δ ← Στ+ni=τ+1(Ri − R) + q(Sτ+n, Aτ+n, w) − q(Sτ, Aτ, w), then R ← R + βδ and w ← w + αδ∇q(Sτ, Aτ, w).

There is no episode to end: the loop runs as long as the agent does. β must be small, so that R follows the long-run average rather than the last few rewards. The figure's agent uses n = 4, α = 0.1, β = 0.0001 and ε = 0, and starts with every weight and R at 0, which is optimistic too: R = 0 expects no failures at all. A failure puts −1 in the windows of four updates; between failures, rewards of 0 beat a negative R, which adds a little to every TD error.

6Summary

The key ideas next to their NumPy equivalents, for a linear estimate. x is the feature vector of St and At, x_next that of St+1 and At+1, and xs_next holds the feature vectors of St+1 with each action, as rows. In the n-step rows, rs holds the n rewards after At, and x_n the feature vector of St+n and At+n; rewards holds the rewards of a long run.

Linear action values
q(s, a, w) = wTx(s, a)
q_hat = w @ x
Greedy action
A*t+1 = argmaxa q(St+1, a, w)
a_star = np.argmax(xs_next @ w)
Semi-gradient Sarsa
w ← w + α[R + γq(S′, A′, w) − q(S, A, w)]x(S, A)
g = r + gamma * w @ x_next
w += alpha * (g - w @ x) * x
n-step semi-gradient Sarsa
w ← w + α[Gt:t+n − q(St, At, w)]x(St, At)
g = rs @ gamma ** np.arange(n)
g += gamma ** n * w @ x_n
w += alpha * (g - w @ x) * x
Average reward
r(π) = limh→∞ 1h Σht=1 E[Rt]
r_pi = rewards.mean()
Differential semi-gradient Sarsa
δ = R − R + q(S′, A′, w) − q(S, A, w), R ← R + βδ, w ← w + αδx(S, A)
delta = r - r_bar + w @ x_next - w @ x
r_bar += beta * delta
w += alpha * delta * x
Differential n-step Sarsa
δ = Στ+ni=τ+1(Ri − R) + q(Sτ+n, Aτ+n, w) − q(Sτ, Aτ, w)
delta = (rs - r_bar).sum() + w @ x_n - w @ x
r_bar += beta * delta
w += alpha * delta * x
